## 二、各來源筆記

### 1–2. 內政部系統(✅ 已於 2026-08-18 下載驗證)

- 下載連結:`https://religion.moi.gov.tw/Report/temple.xml`(資料集頁:dataset/8203)
- **筆數:12,422 筆**立案寺廟;檔案約 6.3 MB
- **欄位(12 欄)**:編號、寺廟名稱、主祀神祇、行政區、地址、教別、登記別、電話、負責人、其他、**WGS84X、WGS84Y**(⚠️ 頁面欄位說明未列座標,實際資料內含)
- **座標完整度:11,919/12,422(96.0%)**,503 筆缺座標待補
- **授權:政府資料開放授權條款-第1版**(散布時須標示出處)
- 提供機關:內政部宗教及禮制司;不定期更新
- 教別分布:道教 9,816、佛教 2,291、一貫道 242、其餘零星
- 主祀神祇前幾名:福德正神 1,262、釋迦牟尼佛 976、**天上聖母 909**、玄天上帝 571、觀世音菩薩 423、關聖帝君 422、觀音佛祖 329、保生大帝 268、五府千歲 266;玉皇、地藏、阿彌陀佛未進前 20
- **主祀神祇命名不一致(已依 D9 雙軌制處理)**:全量共 1,950 種主祀神名(媽祖即有「天上聖母」909、「媽祖」66 筆等)。政策=原名保留(mainDeityRaw)+ 系統歸類(deitySystems);對照表 `data/deities.js`,匯入管線 `tools/import-moi-data.js` 產出 `data/moi-temples.js`(全量底層,12,422 筆)與未比對名稱報告(data/raw/deity-names-report.tsv)
- **資料品質備註**:53 筆主祀神祇未記載(保留為「未記載」);5 筆座標為 (0,0) 等無效值(匯入時歸零視同缺座標);六大源流系統歸類筆數:媽祖 1,041、觀音 1,046、關聖帝君 569、玉皇 152、阿彌陀佛 101、地藏 98
- 驗證副本存於 `data/raw/temple.xml`(已 .gitignore,不進版控)
- 統計區「寺廟分布圖」不再必要(座標已內含),保留為備援來源
- 缺**創建年代與沿革**欄位,源流資訊完全不在其中 → 仍需來源 6、7 策展

### 4–5. OSM / Wikidata(互補)

- 座標品質佳,但台灣民間信仰廟宇的 tag 與命名不一致(小祠、私壇 coverage 未知)。
- 適合用來補齊座標、英文名,不適合作為主檔。

### 7. 源流資料(最大工作量)

- 分香/謁祖關係沒有現成開放資料集,需從各廟沿革志、學術文獻、廟方網站人工整理。
- 建議:**先做單一神明(如媽祖)的完整源流網絡作為 MVP**,驗證資料模型後再擴展。
- 每筆源流邊都應記錄出處(evidenceUrl),供查證。

## 三、授權注意事項

- 政府開放資料(開放政府資料授權條款)允許再加利用,但散布時需標示出處;
  實際條款版本(1.0)下載後確認。
- OSM 為 ODbL,與其他來源混編衍生資料庫時有授權傳染問題,建議僅作查詢核對、
  不直接複製入 repo,或明確分開存放。
- 各廟官網文字沿革具著作權,引用時以改寫+連結出處處理。

## 四、定案組合(2026-08-18 驗證後)

```
全量底圖:來源 1(8203 XML,12,422 筆、含 WGS84 座標 96%、授權條款第1版)
```
