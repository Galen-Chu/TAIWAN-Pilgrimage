## 二、各來源筆記

### 1–2. 內政部系統(主要候選)

- dataset/8203 提供 CSV 下載,欄位含**主祀神祇**——這是「依神明瀏覽」的關鍵欄位。
- 統計區的「寺廟分布圖」版本附 WGS84 座標,可省去大規模地理編碼工作。
- 立案寺廟總數約上萬筆(實際數字待下載驗證)。全量載入前需評估前端效能
  (marker cluster、向量圖層或分縣市切檔)。
- 缺**創建年代與沿革**欄位,源流資訊完全不在其中 → 需另循來源 6、7 策展。

### 4–5. OSM / Wikidata(互補)

- 座標品質佳,但台灣民間信仰廟宇的 tag 與命名不一致(小祠、私壇 coverage 未知)。
- 適合用來補齊座標、英文名,不適合作為主檔。

### 7. 源流資料(最大工作量)

- 分香/謁祖關係沒有現成開放資料集,需從各廟沿革志、學術文獻、廟方網站人工整理。
- 建議:**先做單一神明(如媽祖)的完整源流網絡作為 MVP**,驗證資料模型後再擴展。
- 每筆源流邊都應記錄出處(evidenceUrl),供查證。

## 三、授權注意事項

- 政府開放資料(開放政府資料授權條款)允許再加利用,但散布時需標示出處;
  實際條款版本(1.0)下載後確認。
- OSM 為 ODbL,與其他來源混編衍生資料庫時有授權傳染問題,建議僅作查詢核對、
  不直接複製入 repo,或明確分開存放。
- 各廟官網文字沿革具著作權,引用時以改寫+連結出處處理。
