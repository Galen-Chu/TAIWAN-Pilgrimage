# 核心概念說明 | Concept Notes

> 本文件說明「台灣進香地圖」轉向後的核心概念、名詞定義與資料模型草案。
> 轉向日期:2026-08-18。原「香客大樓地圖」定位見 git 歷史。

## 一、為什麼轉向

原專案以「香客大樓(住宿)定位」為核心，但台灣進香文化的重點不止住宿:
神明從哪裡來、在哪裡落地生根、香火如何分傳,以及**每一個人自己的進香軌跡**,
才是這張地圖真正想回答的問題。

## 二、三層地圖結構

### 1. 廟宇節點(Temples)

地圖的基礎圖層。每間廟宇是一個節點,包含:

- 名稱(中/英)、主祀神、配祀神
- 地址、座標、區域
- 創建年代、沿革摘要
- 聯絡資訊(電話、網站)
- 香客大樓資訊(沿用舊資料,作為規劃進香住宿的屬性)

### 2. 神靈落地點與源流連結(Deity Landing Points & Lineage Links)

**「落地點」指神靈在台灣具體落地生根的位置。** 在台灣民間信仰脈絡中,
神靈的「落地」通常透過以下幾種形式發生:

| 類型 | 說明 | 舉例 |
|------|------|------|
| 歷史登陸點 | 神像隨移民或艦隊渡海,首次踏上台灣土地的位置 | 1661 年鄭成功艦隊媽祖神像於鹿耳門登陸 |
| 開基廟 | 該神明在台灣(或某地區)最早供奉的廟,常持「開基」神尊 | 開基媽祖、開基觀音 |
| 祖廟 | 分香體系中的源頭廟,子廟定期回謁 | 湄洲媽祖祖廟(中國)之於台灣各媽祖廟 |
| 分香子廟 | 自祖廟分香(分靈、分火)建立的廟 | 各地自北港朝天宮分香的媽祖廟 |

**源流連結**是廟宇之間的「邊」,記錄傳承關係:

- **分香(分靈)**:子廟自主祀廟迎請香火建立新廟
- **謁祖進香 / 割火**:子廟定期回祖建進香、割火(更新靈力)
- **遶境路線**:重要進香/遶境活動的行經路線(如大甲媽祖遶境、白沙屯媽祖進香)

首批建置的神明源流系統(已定案 2026-08-18):
**媽祖、關聖帝君、玉皇(天公廟)、觀音菩薩、地藏菩薩、阿彌陀佛**;
建議由媽祖開始(文獻最豐富、既有資料最多),依次完成六系統。

媽祖首批源流已建(2026-08-18):`data/lineage.js` 收錄 10 筆,
含外部源頭(湄洲媽祖祖廟、笨港天后宮)與分香/謁祖/遶境關係,
每筆標註 status(確定/存爭議/待查)與 source 出處(待補具體文獻);
新增廟宇節點:澎湖天后宮(全台最古媽祖廟,開基廟)。

> ✅ 已定案(2026-08-18):採**分層**呈現——全量立案廟宇為淺色底圖,
> 精選落地點(開基廟、祖廟、歷史登陸點)為強調圖層。見 [REQUIREMENTS.md](REQUIREMENTS.md) D1。

### 3. 個人進香之路(Personal Pilgrimage Journey)

記錄使用者自己的進香史:

- **參拜紀錄(check-in)**:哪一天、去了哪間廟、向哪位神明參拜、備註
- **進香足跡**:把參拜紀錄依時間連成路線,形成個人進香地圖
- **統計**:走訪廟數、主祀神涵蓋、區域涵蓋、年度比較
- **與源流連結互動**:例如知道自己參拜過的媽祖廟中,哪些屬同一分香系統

> ✅ 已定案(2026-08-18):localStorage 儲存 + JSON/GPX 匯入匯出,暫不做後端帳號。
> 見 [REQUIREMENTS.md](REQUIREMENTS.md) D4。

## 三、資料模型草案(未定案)

```text
Temple(廟宇節點)
├── id, nameZh, nameEn
├── mainDeity(主祀神)、subDeities(配祀神)
├── address, lat, lng, region
├── foundedYear(創建年代)、history(沿革摘要)
├── lodging(香客大樓資訊,沿用舊資料)
└── landingType?(落地屬性:歷史登陸點/開基廟/祖廟/分香子廟/一般)

Lineage(源流邊)
├── fromTempleId → toTempleId
├── relation(分香/謁祖進香/割火/遶境)
├── year, note, source(資料出處)
└── evidenceUrl(佐證連結,廟史、文獻)

PilgrimageLog(個人參拜紀錄)
├── templeId, date
├── note, photos?(規劃中)
└── routeId?(屬於哪次進香行程)
```

> 語言政策已定案:中文為主;`nameEn` 等英文名稱欄位僅精選落地點必填。
> 個人參拜紀錄存於 localStorage,可透過 JSON(完整備份)與 GPX(足跡路線)匯入匯出。

## 四、名詞表

| 名詞 | 英文 | 說明 |
|------|------|------|
| 進香 | pilgrimage | 到祖廟或重要廟宇參拜、割火的行程 |
| 分香 / 分靈 | incense division / statue division | 從母廟迎請香火或神像建立新廟 |
| 謁祖 | ancestral visit | 子廟回祖廟參拜 |
| 割火 / 掬火 | fire-gathering | 回祖廟取得香火更新神靈靈力 |
| 開基 | founding (statue/temple) | 該地最早供奉的神尊或廟宇 |
| 遶境 | inspection tour | 神明巡視境內的游行 |
| 香客大樓 | pilgrim building | 廟方提供進香客住宿的建築 |
